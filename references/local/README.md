# 本地参考文件

本目录保存个人下载与导出文件。除本说明外，内容默认被根目录 `.gitignore` 忽略，不随 Git 提交发布。

整理前已有的下列文件已移动到这里并保留原内容：

- `cuda-programming-guide.pdf`：本地 CUDA 官方指南副本。
- `大模型训练算子开发与优化学习路径.docx`：学习路线的 Word 导出；维护入口为 `docs/learning-path.md`。
- `site-previews/`：原文档站预览截图。

获取参考文档请使用 [NVIDIA 官方入口](https://docs.nvidia.com/cuda/cuda-programming-guide/index.html)。本目录的文件不是运行示例、执行检查或构建文档站的必需输入。

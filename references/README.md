# 参考资料

## CUDA 官方文档

主要参考 NVIDIA [CUDA Programming Guide](https://docs.nvidia.com/cuda/cuda-programming-guide/index.html)，性能测量补充参考 [CUDA Best Practices Guide](https://docs.nvidia.com/cuda/cuda-c-best-practices-guide/index.html)。官方文档和图片保留原始权利与声明，详见[第三方说明](../THIRD_PARTY_NOTICES.md)。

中文参考文档站位于 [cuda-docs](../cuda-docs/README.md)，现有第一、二章正文已翻译，第三至六部分为目录框架。维护正文时以网站小节页面为准。

## 历史译稿

[CUDA 指南历史译稿](cuda-programming-guide/legacy/README.md)保留迁移前的长章 Markdown、目录与第一章图片。它们用于追溯，不覆盖网站后续翻译。

## 本地下载与导出

个人下载的 PDF、Word 导出和预览图保存在 [local](local/README.md)，默认不进入 Git。公开仓库使用官方文档链接作为参考入口，不依赖本地 PDF 才能运行代码或构建网站。
